# all-world-flag

Flag props/maps for **54 countries**, useful for custom interiors, embassies,
events and shop decorations. Community contributed — the repo keeps growing as
more get added.

## Installation

1. Copy the resource into your `resources` folder.
2. Add to your `server.cfg`:

```cfg
ensure all-world-flag
```

3. Spawn a flag with a trainer or a `CreateObject` call using the prop name for
   the country you want (e.g. `Algeria`, `Argentina`, ... — one folder per country).

## Credits

All maps are contributed by many members. Thanks to all and the OG creators —
